# Support

- Consultez d’abord le README, les limites connues et la documentation de déploiement.
- Pour un bug reproductible, utilisez le modèle « Signaler un bug » dans les issues GitHub.
- Pour une évolution, utilisez le modèle « Demander une fonctionnalité ».
- Pour une vulnérabilité, suivez exclusivement [SECURITY.md](SECURITY.md).

Le support ne peut pas garantir la compatibilité avec un site tiers particulier : CAPTCHA, anti-bot, authentification, WebSockets et applications JavaScript complexes font partie des limites documentées.
